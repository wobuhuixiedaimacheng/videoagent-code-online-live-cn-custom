WorkBuddy 结构，改造成 AIGC 内容生产工作台

结论：借它的“任务入口 / 专家市场 / 项目空间 / 自动化 / 连接器”心智，但业务内核全部换成 AIGC 内容资产生产，不做泛办公。

WorkBuddy 模块怎么迁移

新建任务保留

变成 AIGC 命令入口：生成视频、拆场景、改爆款、批量产图、生成一周内容。

助理替换

不叫通用助理，改成 Orchestrator：负责拆任务、调用子 Agent、写入项目文件。

项目保留

一个项目就是一个品牌 / 活动 / 产品线，内部包含 Brief、脚本、分镜、素材、发布计划。

专家垂直化

从泛职业专家，变成 AIGC 专家团：脚本、镜头、视觉提示词、平台运营、合规审查。

自动化内容化

从提醒/日报，变成每日选题、热点追踪、竞品拆解、素材生成、定时发布准备。

更多/资料库保留

变成品牌知识库、历史爆款库、产品素材库、平台规则库、灵感库。

三种产品方向

A. WorkBuddy 皮肤版

最快，像截图。但只是换壳，容易变成泛办公工具，AIGC 差异不够强。

推荐

B. AIGC Agent 工作台

借 WorkBuddy 信息架构，核心围绕内容项目、场景拆解、子 Agent 编排、素材和发布资产。

C. 纯 CC 终端式

最有 Agent 感，但 C 端和小 B 上手成本高，不利于营销产品转化。
