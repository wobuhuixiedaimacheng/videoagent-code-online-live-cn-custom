# 剪辑节奏

分镜阶段产出两份东西：`storyboard.json` 是一个个镜头，`timeline.json` 是这些镜头**排起来是什么节奏**。
后者最容易被写成前者的摘要——每个 beat 抄一遍镜头内容，`pacing` 全写 steady，`editNote` 全写「顺剪」。那样等于没做节奏设计。

本技能覆盖：`timeline.json` 的 `principle` 和 `beats`（`role`、`pacing`、`editNote`），以及镜头上的 `emotionBeat`。

## 一、principle：这一条决定其余所有 beat

`principle` 是全片的剪辑原则，一句话，要能被后面每个 beat 检验。

- 好：「全片跟着女主的情绪走：她越乱，切点越密；她做决定的那一刻给最长的镜头。」
- 好：「前 3 秒不给任何环境交代，直接进冲突，第 4 秒才补地点。」
- 好：「产品每出现一次就更近一档，最后一次是大特写接 CTA。」
- 差：「节奏明快，张弛有度。」——不可检验

写完 `principle`，回头看每个 beat：这个 beat 遵守了吗？违反了是有意的吗？

## 二、节奏是曲线，不是速度

`pacing` 只有 fast / steady 这类粗粒度取值，但你要设计的是**它们的排布**。

全片 fast 和全片 steady 一样糟：前者让人疲劳，后者让人划走。有效的节奏来自**对比**。

一条可用的默认曲线：

1. **开场（hook）**：fast。短镜头连切，信息密度高，不给观众判断的时间。
2. **展开（proof）**：steady 为主，中间插一两处 fast 制造推力。
3. **转折**：一次明显的节奏断裂——要么突然变快，要么突然停下。停下比变快更有力。
4. **收尾（cta）**：镜头变长，让观众有时间接收信息并做出动作。

**最重要的节奏手段是「停」。** 全片最长的那个镜头应该落在情绪峰值或决定时刻。一直快，观众感受不到快。

## 三、role 怎么分

`role` 说的是这一段在说服链条上干什么，不是它在讲什么内容。

- `hook`：留人。只负责让观众不划走，可以不完整、不交代。
- `proof`：给理由。演示、对比、证据、故事推进。
- `cta`：要行动。明确说出下一步做什么。

短视频里 `hook` 通常只有前 2–3 秒，`cta` 只有最后 2–3 秒，中间全是 `proof`。
**如果你的 beats 里 hook 占了前 8 秒，那不是 hook，是慢热的开场。**

## 四、editNote：写切点，不是写内容

`editNote` 最容易写成镜头内容的复述。它该写的是**这一刀怎么切**。

- 好：「切在她抬眼的瞬间，不等她说完上一句」
- 好：「硬切，不留缓冲，前一镜的环境音延续到这一镜」
- 好：「这里停两拍再切，让观众看清桌上的东西」
- 好：「用手的动作做匹配剪辑，上一镜她合上笔记本，这一镜她推开门」
- 差：「切到她的近景」——那是镜头，不是切点

几种值得写进 `editNote` 的切法：

- **动作剪辑**：切在动作进行中，不等动作做完。最自然，也最常用。
- **匹配剪辑**：前后两镜有形状、动作或方向的呼应，用它做场景跨越。
- **声音先行**：下一镜的声音提前进来，画面后到。转场最平滑的方式。
- **留白**：切之前多停一拍。用在需要观众消化的信息之后。

## 五、emotionBeat：镜头上的情绪坐标

`emotionBeat` 写的是这一镜在情绪线上的**位置**，不是形容词。

- 好：「压抑到临界，还没爆发」
- 好：「刚意识到自己错了，还没承认」
- 好：「松了一口气，但还有余悸」
- 差：「悲伤」「紧张」——是标签，不是位置

判断标准：把全片的 `emotionBeat` 按顺序抄成一列，应该能读出一条有起伏的线。
如果连着五个镜头都写「紧张」，要么是没设计，要么是这五个镜头该合并。

**情绪曲线要和 `pacing` 对得上。** 情绪在收紧、节奏却在放慢，这可以是有意的反差，但要在 `editNote` 里说明；没说明就是失控。

## 六、和上游的对齐

- `beats` 里的 `sceneId` 对应的是**镜头 id**，不是场景 id。
- `start`／`end` 按全片时间轴累计连续，和镜头的时间轴对得上，不要各自从 0 开始。
- beats 不必和镜头一一对应：一个 beat 可以覆盖连续几个镜头，那正是节奏段落的意思。

## 七、反模式

- `principle` 是形容词句，没法拿来检验任何一个 beat。
- `pacing` 全片一个值。
- `editNote` 每条都在复述镜头内容。
- `emotionBeat` 是情绪标签的重复，读不出曲线。
- 全片没有一个明显更长的镜头。
- hook 占了开头的三分之一以上。

## 八、交付前自检

1. `principle` 能拿来判断某个 beat 对不对吗？
2. 把 `pacing` 抄成一列，看得出起伏吗？
3. 全片最长的镜头落在情绪峰值上吗？
4. `editNote` 写的是切点还是内容？
5. 把 `emotionBeat` 抄成一列，读得出一条线吗？
6. hook 是不是超过 3 秒了？
