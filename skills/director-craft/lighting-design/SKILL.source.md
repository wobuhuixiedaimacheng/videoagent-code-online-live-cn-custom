# 光影设计

光影在这套数据结构里分两层：

- **场景层** `instance.lighting`：keySource（主光来源）、keyDirection（主光方向）、colorTemperature（色温）、contrastRange（明暗关系）、contrast（对比度）、ambient（环境光）、practicals（实景灯光）、windowLight（窗外光线）、shadowDirection（阴影方向）、effects（雾气、逆光、灰尘颗粒等）。
- **镜头层** `lightingNote`：这一镜的光线方向和质感。

**镜头层必须服从场景层。** 阶段指令已经写死了这条：`lightingNote` 的主光方向要和所属场景 `instance.lighting` 一致，不能自己另起一套。本技能讲的是这两层各自怎么想清楚。

## 一、先定主光，其他都是它的附属

一个场景只有一个主光。定主光就是回答两个问题：**光从哪来（keySource）、往哪个方向打（keyDirection）**。

主光来源要写**具体的物理光源**，不要写效果：

- 好：「左侧落地窗的自然光」「头顶单盏吊灯」「桌面台灯」「对面楼的霓虹招牌」「车头灯」
- 差：「柔和的光」「电影感布光」「氛围光」——这些是结果，不是来源

**主光来源一旦定了，整场戏不能变。** 场景母版里窗户在左边，这个场景所有镜头的亮面就都在人物左脸；某一镜写成右脸亮，观众会觉得换了个房间——这是场景一致性质检最常抓到的问题。

`keyDirection` 用可执行的方位写：「从画面左前方 45 度斜下打来」「正上方垂直向下」「人物身后，形成逆光轮廓」。

## 二、光比决定情绪，不是决定亮度

`contrast` 和 `contrastRange` 说的是亮面和暗面差多少，这一栏比「亮不亮」重要得多。

- **低光比**（暗面只比亮面暗一点）：日常、安全、温和、轻松。生活场景、产品展示、教程。
- **中光比**：常规叙事，绝大多数对话戏。
- **高光比**（暗面几乎黑掉）：紧张、孤立、危险、审讯感。冲突、转折、悬疑。
- **极高光比**（只有轮廓）：剪影。身份未揭示、气场压迫、结尾抽离。

**情绪转折点要靠光比变化标记出来。** 一场戏从平静走到爆发，光比应该跟着收紧；从头到尾一个光比，情绪就是平的。

## 三、色温说时间和冷暖

`colorTemperature` 同时承担两件事：交代什么时候，以及让观众感觉冷还是暖。

- 暖（约 2700–3500K）：黄昏、室内灯光、亲密、回忆、安全
- 中性（约 4500–5500K）：日光、办公、客观、冷静
- 冷（6000K 以上）：清晨、阴天、月光、疏离、医疗与科技感

**冷暖对撞比单一色温更有信息量。** 室内暖灯 + 窗外冷调天光，人物在两种光之间，画面立刻有了内外、有了取舍。`windowLight` 这一栏就是干这个用的。

**色温要和 script 里的时间对得上。** 脚本写深夜，场景却写正午日光，下游的每一张图都会错。

## 四、practicals：画面里看得见的灯

`practicals` 指入画的实景光源——台灯、屏幕、烛火、招牌、车灯、手机屏。

它的价值是给**光找到理由**。观众不会分析布光，但会本能地判断「这个亮度合不合理」。人物脸上有光却找不到光源，画面就假。

写法：「书桌台灯在她右手边，是画面里唯一的暖光源」「手机屏幕自下而上照亮她的下巴」。

夜戏尤其依赖 practicals——没有 practicals 的夜戏，只能靠不知道从哪来的环境光，成片必然是灰扑扑一片。

## 五、shadowDirection 和 ambient

- `shadowDirection` 是主光方向的镜像，必须自洽：主光从左前方来，阴影就落在人物右后方。这一栏写错，观众说不出哪里不对，但会觉得画面「贴上去的」。
- `ambient` 决定暗部有多少细节。全黑的暗部适合高反差的紧张段落；日常场景要给暗部留一点环境反射光，否则人物像被抠图。

## 六、effects 谨慎用

`effects` 里的雾气、逆光、灰尘颗粒是**放大器，不是补救措施**。构图和光比不对的画面，加了逆光只会更乱。

- 雾气：让光线可见，交代纵深。适合有强方向光的场景。
- 逆光：勾轮廓，分离主体和背景。适合人物从暗处走向亮处。
- 灰尘颗粒：让空气有质感。适合老屋、仓库、阳光斜射的室内。

一个场景最多用一到两项，全开就是滤镜堆砌。

## 七、lightingNote 怎么写

一句话，讲清 **方向 + 质感 + 这一镜的落点**，并且和场景主光对齐：

- 好：「沿用左侧窗光，主光斜落在她左脸，右脸没入阴影，光比偏高」
- 好：「逆着窗光拍，人物成半剪影，只有肩线和发梢有轮廓光」
- 差：「光线柔和自然」——没有方向，没有落点
- 差：「专业影视级布光」——形容词

**同一场景拆出的多个镜头，lightingNote 各写各的落点，但主光方向必须是同一个。**

## 八、交付前自检

1. 这个场景的主光来源写的是具体物理光源吗？
2. 整场戏主光方向一致吗？亮面始终在人物同一侧吗？
3. `shadowDirection` 和主光方向互为镜像吗？
4. 光比和这场戏的情绪对得上吗？转折点有变化吗？
5. 色温和脚本里的时间对得上吗？
6. 夜戏有 practicals 吗？人物脸上的光找得到来源吗？
7. `lightingNote` 写了方向和落点，还是只有形容词？
