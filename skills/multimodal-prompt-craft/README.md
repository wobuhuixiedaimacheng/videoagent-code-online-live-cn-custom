# 多模态提示词技能包

VideoAgent 的自有技能包。三个原子技能，管的是**图片素材和声音进入视频请求时的那一层**。

## 这个包解决什么

`skills/director-craft/` 管的是画面怎么拍（景别、运镜、光影、节奏），
`skills/video-prompt-engineer/` 管的是剧本怎么变成分镜表。

这个包管的是它们之间那道缝：**分镜写完了、角色图和场景图也生成了，这些东西怎么装进一次视频请求。**

| 技能 | 管什么 | 阶段 |
|---|---|---|
| reference-slots | 每张参考图挂哪个位（首帧 / 关键帧 / 身份参考），提示词怎么指代 | 素材提示词 |
| retention-brief | 每张参考图「继承什么、不继承什么」 | 素材提示词 |
| soundscape-layers | 人声 / 环境动效 / 配乐三层分别怎么写 | 分镜 |

这一层没有下游兜底：画面质检（`lib/videoQa.ts`）抽帧送多模态模型，看得见崩指头和换脸，
**看不见「这个姿势是从参考图抄来的」**——它拿不到参考图。这里漏了就一路漏到用户眼前。

## 产品边界

- 技能只影响**写法**，不改字段契约。参考位的字段名、数量限制一律以 `app/api/video/render/route.ts`
  的实际实现为准；技能正文和实现冲突时，以实现为准。
- 三个位的字段名来自本仓库对当前视频网关的实测。**换底层视频模型时这三份都要复核**，
  尤其是身份参考位——它的键名本来就是靠 `VIDEO_IDENTITY_REFERENCE_FIELD` 兜着的。
- 面向用户的名称是「多模态提示词」，不暴露技能目录名。

## 来源

因该仓库无许可证而没有引入，改为 clean-room 自研。读取范围、借鉴的三条方法、

## 改这个包

技能正文可以直接改——它是自有资产，不像 `skills/` 下的 vendor 包那样需要回上游提 PR。
改完记得同步：

- 新增或删除技能目录 → `lib/localSkills.ts` 的 `PACKS` 和 `STAGE_OVERRIDE`
- 想让某个技能在特定片种自动加载 → `lib/genreSkillRouter.ts` 的 `GENRE_STAGE_SKILLS`

**当前三个技能全部挂在 `candidates` 上，没有一个进 `required`。** 这是有意的：
短剧和视频生成准备两个片种的分镜格已经注到 10622 字符，逼近 `MAX_REQUIRED_SKILL_CHARS`（12000），
再加必读会把 `edit-rhythm` 挤成候选。候选不占注入额度，模型按需 `read_skill` 取。

要改成必读的话，`reference-slots` 是最该进的那个——它挡的是整镜作废级别的错误。
但必须同时把分镜格那条 `required` 数组重排一遍，把要丢的那个想清楚。
