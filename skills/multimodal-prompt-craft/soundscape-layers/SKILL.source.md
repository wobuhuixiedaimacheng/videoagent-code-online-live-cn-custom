# 声音分层

声音在提示词里最常见的写法是一句「电影音效」，然后就没有了。这句话什么也没规定，所以模型什么都可能给。

这个技能只做一件事：**把一镜的声音拆成三层，分别下笔。** 三层的规则完全不同，混在一起写必出事。

| 层 | 是什么 | 画面里找得到声源吗 | 归谁管 |
|---|---|---|---|
| 人声 | 对白、旁白、内心独白 | 找得到（对白）/ 找不到（旁白） | `voiceMode` 契约，不归本技能 |
| 环境与动效 | 脚步、开门、风、雨、车流、碰撞 | 找得到 | 本技能 |
| 配乐 | 背景音乐、情绪铺底 | **找不到，也不该找到** | 本技能 |

## 一、人声层：本技能不做决定，只做核对

人声由项目级的 `voiceMode` 决定（`dialogue` 对白 / `narration` 旁白 / `silent` 无人声），默认是**对白**。

要核对的只有两条：

- 台词必须写成 `角色名：台词`，说话人得是真名。写「旁白：…」「画外音：…」「解说：…」会被拦下来——格式对了内容还是旁白，这个洞是堵死的。
- 台词里不能带括注。`（冷笑）`、`【第二章】`、`(sighs)` 这类东西在剧本里是给人看的，到了视频模型手里只有两种下场：被念出来，或者被画到画面上。

第二条尤其要注意 `【 】`：它在主流视频模型的提示词规范里就是字幕标记，写进台词等于主动要求模型贴一行它画不好的汉字。

## 二、环境与动效层：只写画面里看得见的

这一层的唯一规则是**声画对位**：写进去的每一个声音，画面里都要有对应的东西。

- 好：「她推门进屋，木门轴的吱呀声，门在身后合上的闷响」——门在画面里。
- 好：「窗外持续的雨声，雨点打在铁皮雨棚上」——雨棚在画面里。
- 差：「紧张的音效」——不是声音，是形容词。
- 差：「远处传来警笛」——画面里没有警笛，模型只能靠猜；猜错了它会把警车画进来。

**画面外的声音要么不写，要么明确标注它是画外的。** 不标注，模型解决歧义的方式往往是把声源补进画面。

数量上：一镜两到三个具体动效就够了。列满六七项，模型会挑着做，你不知道它挑了哪几个。

## 三、配乐层：默认没有

项目默认的声音策略是 **`电影音效，无配乐，无字幕`**。三项都要写出来，缺一项就是给模型留了自由发挥的口子。

「无配乐」是默认值，理由不是省事：

- 单镜生成的配乐互相之间没有连续性，十二段片子拼起来是十二段不搭的音乐。
- 配乐属于拼接阶段的事——那时候是整片一条音轨，才谈得上情绪曲线。

确实要配乐的时候（整片风格片、无人声口播），**配乐必须单独成句，和画面描述隔开**：

- 好：「配乐：低音提琴单音铺底，无旋律。」
- 差：「伴随着低沉的大提琴声，她走进房间」——写在画面描述里，模型可能真给你把大提琴画进房间。

这一条是配乐层和环境层的根本区别：**环境音要有声源，配乐必须没有声源。** 两者混写，模型会把配乐当环境音处理，然后去找声源。

## 四、三层的书写顺序

一镜的声音部分按固定顺序写在提示词末尾，不要打散穿插在画面描述里：

```text
[画面描述] + [人声：角色名：台词] + [环境与动效：两到三项具体声音] + [声音策略：电影音效，无配乐，无字幕]
```

固定顺序的好处是可核对：交付前扫一眼末尾，三段都在就是齐的。

## 五、反模式

- 整片只有一句「电影音效」，没有任何具体动效。
- 台词里带 `（）`、`【】`、`()` 括注。
- 说话人写成「旁白」「画外音」「解说」，绕过对白格式。
- 配乐写在画面描述的句子里，和人物动作黏在一起。
- 声音策略只写了「无字幕」，漏了「无配乐」，结果一半镜头自带音乐一半没有。
- 写了画面里根本不存在的声源（远处的钟声、楼上的争吵），没有标注是画外音。
- 一镜列了七八个动效。

## 六、交付前自检

1. 这一镜的三层我都过了一遍吗（人声 / 环境动效 / 配乐）？
2. 台词是 `角色名：台词` 吗？说话人是真名吗？有括注吗？
3. 每个动效在画面里都找得到东西吗？找不到的标注画外了吗？
4. 动效数量在两到三项吗？
5. 声音策略三项（音效、配乐、字幕）都写全了吗？
6. 如果有配乐，它是单独一句，还是黏在画面描述里？
